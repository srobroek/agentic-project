# This content is generated, so an edit to it is discarded

You are writing inside a region that `project-setup` rebuilds from fragments. The next
`project-setup apply` overwrites it and your edit is gone, with no warning.

Edit the source instead:

| Destination | Rebuilt by | Edit this |
| --- | --- | --- |
| `.gitignore` managed block | `fold_gitignore.py` | a file in `.gitignore.d/` |
| `.pre-commit-config.yaml` | `merge_hooks.py` | a file in `.pre-commit.d/` |
| `justfile` import block | `gen_justfile.py` | a file in `.just.d/` |
| `.github/workflows/ci.yml` | `gen_caller.py` | the reusable `wc-*.yml` workflows, or `.ci/members.json` |
| `docs/agents/**` | `gen_steering.py` | the layer that owns the section |
| `AGENTS.md` | `install_agents_index.py` | `docs/agents/AGENTS.body.md` |

Then re-run the generator, or `project-setup apply` to run all of them.

Text **outside** a managed block is hand-owned and preserved, so appending your own
recipe to the justfile or your own ignore line below the block is fine. It is the region
between the markers that is not yours.
